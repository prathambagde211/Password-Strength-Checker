# Password Strength Checker

A simple web application that checks the strength of a password using JavaScript regular expressions.

## Features

* Show/Hide Password functionality
* Password strength evaluation
* Strength levels:

  * Weak
  * Easy
  * Medium
  * Hard
* Checks for:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
  * Minimum password length

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

password-strength-checker/

├── index.html

├── style.css

└── script.js

## How It Works

The application uses regular expressions to evaluate password strength:

### Level 1

* At least one letter
* At least one number
* Minimum 6 characters

### Level 2

* At least one uppercase letter
* At least one lowercase letter
* At least one number
* Minimum 8 characters

### Level 3

* At least one uppercase letter
* At least one lowercase letter
* At least one number
* At least one special character
* Minimum 10 characters
